Findora PH Auto Shop

ONE-TIME SETUP
1. Upload this project to a GitHub repository.
2. Connect that repository to your existing Netlify project.
3. In Netlify, add environment variable:
   Key: ADMIN_PASSWORD
   Value: your private password
   Scope: Functions (or all scopes)
4. Trigger a new production deploy.

PUBLIC SHOP
/

ADMIN
/admin.html

DAILY USE
Open /admin.html, enter your password, fill in the product details, then tap Publish Product.
The public homepage updates automatically from Netlify Blobs.
